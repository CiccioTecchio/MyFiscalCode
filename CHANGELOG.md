# 1.0.0

First release of **my-fiscal-code**!

- created action that allow the user to calculate his/her fiscal code
- added unit tests with Jest
- added E2E test with playwright
- added about section
- added privacy section
- added middleware that allow the check for 429: too many requests
- added Docker compose configuration
- deployed on Vercel and available at <https://my-fiscal-code.vercel.app/>
